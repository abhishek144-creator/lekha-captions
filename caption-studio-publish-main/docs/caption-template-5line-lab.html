Five-line caption packs

Fifteen templates where every caption line looks different. Each template is a pack of five line styles that share one palette and one set of fonts: one line is placed creatively, one is plain, one is animated, and so on. As the video plays, each new caption takes the next style, so no two lines in a row look the same. Every style is still built around the caption's important word. Each phone plays a five-line script, and the list under it highlights the line that is on screen.

Tap a phone to restart it from line 1
