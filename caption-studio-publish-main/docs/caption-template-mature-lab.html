Studio caption set

Fifteen restrained, professional caption templates. Each template has one signature motion of its own, its own type pairing and a muted palette; no motion is shared between templates. Inside a template, the five lines change through composition and pacing: subtitle, headline, a big important word, a small label above the line, or a quote, revealed word by word, letter by letter, line by line or all at once. Each phone plays a five-line script; the list under it shows what each line does.
